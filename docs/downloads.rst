.. _model-downloads:

=========
Downloads
=========

Ready-to-use gait2d model bundles, each containing the model config
(``.yaml``), the MuJoCo body (``.xml``), actuator definitions, and a ground
contact definition.

gait2d
======

A basic sagittal-plane gait model, with definitions based on the
`BioMAC-Sim-Toolbox <https://github.com/mad-lab-fau/BioMAC-Sim-Toolbox>`_,
using the ground contact model from
`Nitschke et al. (2020) <https://doi.org/10.1038/s41598-020-73856-w>`_.

:download:`Download gait2d.zip <_generated_downloads/gait2d.zip>`

gait2d (Hunt-Crossley contact)
================================

The gait2d variant with Hunt-Crossley smooth contact points for the
ground contact model.

:download:`Download gait2d_huntcrossley.zip <_generated_downloads/gait2d_huntcrossley.zip>`
